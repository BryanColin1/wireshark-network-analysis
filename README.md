# Wireshark Network Analysis

## Overview

This project demonstrates basic network traffic analysis using Wireshark in a controlled lab environment. The objective is to capture, inspect, and explain common network protocols and identify suspicious or security-relevant traffic patterns.

## Objectives

- Capture network traffic using Wireshark
- Analyze common protocols such as TCP, DNS, HTTP, and ICMP
- Document packet-level observations
- Explain security relevance of network activity
- Build practical traffic analysis skills for cybersecurity roles

## Tools Used

- Wireshark
- Kali Linux / Windows
- VirtualBox
- Markdown
- GitHub

## Planned Analyses

- TCP three-way handshake analysis
- DNS query and response analysis
- HTTP request and response analysis
- ICMP ping traffic analysis
- Suspicious scanning traffic analysis

## Skills Demonstrated

- Packet capture
- Protocol analysis
- Network troubleshooting
- Traffic interpretation
- Security documentation
- Evidence-based reporting

## Disclaimer

This project is performed in a controlled lab environment for educational and defensive security purposes only.
