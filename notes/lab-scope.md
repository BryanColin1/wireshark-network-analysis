# Lab Scope

## Purpose

This lab demonstrates basic packet capture and network protocol analysis using Wireshark. The goal is to understand how common network protocols appear at the packet level and document observations in a clear security-focused format.

## Environment

This analysis is performed in a controlled lab environment using systems owned or controlled by me.

## In Scope

- Local lab network traffic
- DNS lookup traffic
- TCP connection traffic
- HTTP traffic from safe test sites or local lab services
- ICMP ping traffic
- Traffic generated intentionally for educational analysis

## Out of Scope

- Third-party private networks
- Public targets without permission
- Credential capture from real users
- Sensitive personal data
- Production company traffic
- Unauthorized packet capture

## Rules of Engagement

- Capture only traffic generated in the lab environment
- Do not collect or upload sensitive data
- Sanitize screenshots if they show personal information
- Use packet captures only for educational and defensive analysis
