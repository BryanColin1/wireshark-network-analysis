# TCP Three-Way Handshake Analysis

## Objective

Analyze a TCP three-way handshake generated by an HTTP request to `example.com`.

## Environment

| Component | Description |
|---|---|
| Capture Machine | Kali Linux VM |
| Tool | Wireshark |
| Network Mode | NAT |
| Source Host | Kali Linux VM |
| Destination | `example.com` |
| Destination Port | `80/tcp` |

## Command Used

```bash
curl http://example.com
```

The following packets show the TCP three-way handshake created before the HTTP request was sent.

## Packet Analysis

| Step | Packet Type | Source | Destination | Description |
|---|---|---|---|---|
| 1 | SYN | Kali ephemeral port `40162` | Destination port `80` | Client requests to establish a TCP connection |
| 2 | SYN-ACK | Destination port `80` | Kali ephemeral port `40162` | Server acknowledges the request and responds |
| 3 | ACK | Kali ephemeral port `40162` | Destination port `80` | Client acknowledges the server response and completes the handshake |
